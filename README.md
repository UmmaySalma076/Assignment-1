# Assignment 1 · Spec-Driven Development and Harness Engineering

This repository contains the two applications for Part 1 of AI-Augmented Software Development Life Cycle (SE* ZG534).

| Part | Application | Where to start |
| --- | --- | --- |
| 1A | Smart Todo, a deterministic FastAPI task service | [Setup, harness, and evidence](Part-1A/README.md) |
| 1B | Natural-Language Reminder Agent, a FastAPI interpreter using local TinyLlama through Ollama | [Setup, harness, and evidence](Part-1B/README.md) |

Each part has its own Python 3.13 environment, Spec Kit artifacts, tests, and harness. Part 1A checks deterministic behavior, code quality, and security. Part 1B evaluates structured model outputs against a fixed benchmark, including semantic quality and safety criteria. See the respective README for commands and evidence locations.

The harness results support a final human review. Use the evidence and review instructions in each part to identify the result and decision for the submitted version.

The project uses GitHub Spec Kit. The Git history attributes the AI-assisted harness and validation changes to Codex. [GitHub Spec Kit](https://github.com/github/spec-kit)
